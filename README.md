# Loja de Eletrônicos | TED

Projeto acadêmico de estrutura de dados desenvolvido em C# para execução no console.

## Funcionalidades

- Cadastro de produtos com nome, código, preço e estoque.
- Listagem dos produtos cadastrados.
- Busca binária por código ou nome, com ordenação por Selection Sort.
- Remoção de produtos por código.
- Verificação de códigos duplicados.

## Como executar

Com o .NET SDK 8 instalado, abra o terminal na pasta do projeto e execute:

```bash
dotnet run
```

Os produtos são armazenados em memória durante a execução. Os dados são perdidos ao encerrar o programa. Informe valores numéricos válidos quando solicitado.
